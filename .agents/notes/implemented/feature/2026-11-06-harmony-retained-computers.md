# Agent Note: 鸿蒙电脑会话保留与直接切换

Status: implemented

Chat 设置入口可达性已由[三入口决定](../bug-fix/2026-11-12-harmony-magpie-navigation.md)取代；本文的电脑生命周期、保存竞态及历史数据保留边界不变。

## Problem

原外壳只有一个 Codex 网页控制器；选择另一台电脑前先返回列表并卸载旧网页，因而再次连接会回到首页，未发送草稿、滚动和页面状态不能留在原网页。多个网页同时存在后，先前电脑的原生回调、文件选择和下载不能对新电脑生效。

## Decision

- 已打开电脑以规范化网关 `base`（含中继作用域）为键，各自持有 Web 控制器、首次目标 URL、页面 token 和导航代次。仅第一次打开时创建；电脑菜单直接切换已保存或已打开电脑，已打开实例只改变可见性，不调用 `loadUrl`、`refresh` 或返回首页。重命名不更改键或销毁网页。电脑列表最多保存 100 台，不据此预先加载；已经打开但随后被列表容量淘汰的实例仍可在进程中从菜单返回。已打开实例达到 100 时拒绝新实例并提示先移除一台，既有实例仍可切换，不自动丢弃草稿。
- 返回电脑列表只隐藏已打开的 Web，删除电脑按既有确认流程清除其网关 Cookie，并卸载该实例。用户明确选择的通知深链接或新扫码配对可导航到对应控制器；不把普通主机切换变成导航。网页和远端任务保持各自控制，不主动停止模型、不自动重放写入。
- 所有 Web 事件带原实例身份。仅当前实例和 Codex 页签可执行原生操作；隐藏实例的主框架仍按自己的网关来源限制导航，并可在自己的控制器上安装页面适配。切换、回列表或主框架导航使活动代次失效；文件选择必须继续匹配实例、代次、base、完整 URL 和页签，拍照返回不额外要求前台。同步页面控件和前台通知只针对当前实例；切回重新建立通知游标，不补发历史事件。
- 下载只属于启动电脑；切换时取消其原生下载及未保存缓存。已经调用系统保存的源文件保留至保存结束，旧保存的完成不能取消新电脑下载，失败必须标出原电脑；这不代表能撤销已开始的系统文件复制。电脑列表异步写入串行，较旧连接完成不会盖过后选择的电脑。
- Chat 的启停与普通站点切换共享底栏，但隐藏 Chat 时仍可从电脑列表或电脑菜单进入 Chat 设置；停用只卸载 Chat Web，不清 Cookie 或凭据。[Chat 站点决定](2026-11-06-harmony-chat-site.md)负责 URL、凭据和受限 iframe 适配。
- CPA 保留独立服务配置和已加载 Web，仅将底部入口移到 Codex 的更多菜单（电脑列表与已连接页均可打开）。调用原 `selectTab` 切换，不重新加载任何已有服务或 Codex 控制器；选择 Codex 底栏或系统返回可回原会话。[统一紧凑导航](2026-11-06-harmony-flat-navigation.md)负责四入口外观。

## Existing-note audit

[Codey 紧凑操作区](../bug-fix/2026-11-04-harmony-codey-compact-controls.md)与本决定在保留原控件和切回强制同步上部分重叠，原记录仍负责 DOM 接管；[原生相机修复](../bug-fix/2026-11-06-harmony-native-camera.md)仍负责相机分流、手势和缓存生命周期，本决定增加跨电脑身份。Chat 站点记录负责第三方站点，三篇均未被替代。Android 更新交接和网关 Cookie 作用域记录不描述鸿蒙多 Web 生命周期，不变更。

## Alternatives considered

- 仅在菜单列出已保存地址并继续复用一个控制器改动较少，但仍会重载页面、丢失未发送草稿，不能满足直接切换。
- 预先连接全部已保存电脑可减少首次等待，但会启动最多 100 个不必要的 Web，并扩大网络、内存和通知活动；按用户实际打开的电脑懒创建。
- 切换时销毁旧页面并另存草稿可减少驻留内存，但外壳无法完整复制网页内的 URL、滚动、附件和运行状态，也可能错误重放操作；保留原 Web 实例。
- 在切换时立即删除正在保存的下载缓存可简化管理，但系统保存可能尚在使用它，且复制错误可能产生不完整目标；持有到操作结束并报告原电脑上的错误。

## Testing

`node --test mobile/tests/harmony-multihost.test.cjs` 执行生产 Index 方法和真实网关 URL 规则，以隔离控制器模拟不同电脑及同源不同中继作用域；覆盖草稿/URL/控制器保留、重命名、显式深链接、连接保存乱序、隐藏回调、切换再切回的过期相机结果、下载保存迟到完成/失败、停用和重新启用 Chat。`mobile/tests/harmony-upload.test.cjs` 继续验证原相机分流与后台返回边界。模拟对象不等于真实 ArkWeb 实例或 ArkUI 渲染。

## Consequences

已打开的网页随电脑数量占用内存和网络资源；系统回收进程、应用退出、显式刷新或移除电脑后不保证内存草稿保留。既有通知、Cookie 域和服务端权限不因多控制器而扩大。设备上仍需验证多 Web 生命周期、软键盘、下载选择器和四入口实际宽度；本记录的 Node 测试不证明这些实机行为。
