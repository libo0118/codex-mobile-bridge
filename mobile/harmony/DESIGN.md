# 沿用现有移动端界面

本次是原生外壳移植及已有管理页面的页签容器，不重新设计聊天界面。聊天、工作区、账号等页面仍来自同一网关 `web/`，三个共用注入脚本保持原顺序。

原生电脑列表沿用 Android `MainActivity` 的视觉值：页面 `#f5f5f3`、白色卡片、主要文字 `#202124`、次要文字 `#777b80`、浅色操作面 `#f4f5f7`、移除操作 `#b44235`；页面边距 20 vp，卡片圆角 22 vp，按钮圆角 12–16 vp，主要操作高度 54 vp，次要触控不低于 44 vp。标题 30 fp、分区标题 19 fp、电脑名 17 fp、正文 14–16 fp、辅助文字 12–13 fp。文本允许系统缩放，连接入口、菜单和图标等价操作保留可读名称。

主任务依次是：核对并连接自己的电脑、继续现有聊天、查看文件结果、返回电脑列表。Keeper / CPA / Magpie 的工具栏复用相同颜色、按钮和文字规则；站点内容本身不改造。首次打开后使用独立且常驻的 Web 实例，切换仅改变可见性。站点设置改变 URL 和用户主动刷新才重新加载；应用重启后的重新加载是系统生命周期边界。

管理页工具栏保留历史返回、登录信息与带可访问名称的 44 vp 更多按钮；刷新和站点设置进入同一个菜单，站名单行省略，为 320–360 vp 窄屏留出操作空间。历史返回不调用刷新或替换 URL。此布局仍需鸿蒙设备的实际渲染验证。

安全区由默认非沉浸窗口保留。Codex 页面在通过来源与令牌验证后可同步顶部状态栏背景；底部系统手势栏固定与原生导航一致的浅灰绿色。管理站点无此桥接权限。密码与私密入口的操作在原生登录信息面板中完成，不增加网页中不可见的自动提交动作。

## 已选择的 A 底栏 + C 图标方案

2026-10-19 用户最终明确选择 A「清线桥接」的底栏样式，搭配 C「彩色磁片」的四个菜单图标与 App 图标。桌面显示名缩短为 `Codex`，应用 bundleName 保持不变；Harmony build 34。

App 主形是森林绿与陶土橙的两块磁片和一条连接留白，背景 `#FFF1D9`，原始 SVG、透明前景和1024px PNG保存在 `branding/`。主形全部位于中央75%安全圆。四个导航图标为24vp独立填充SVG：聊天终端、账本、双端路由、鸟翼；默认 `#5C625E`，选中分别用深绿、赭色、蓝与陶土色，并增加内部留白几何。

底栏采用A的轻浅布局：`#F0F4F0` 底、白色圆角选中块，图标上标签下。标签默认 `#526363`、选中 `#103F45`，12fp、最小触区高度64vp；允许系统字体缩放增加布局高度，保留完整可访问名称。切换只沿用原有 selectTab 与 Web 可见性逻辑，不增加刷新或重建操作。

图形来自 OpenDesign 四方向预览的 C 原稿，布局来自 A；A/B由OpenDesign生成，C/D由当前Codex补齐后通过OpenDesign官方文件工具装配。未将含聊天或IP的完整截图提交到设计或仓库。原生编译和真机显示的验证范围以对应构建与实机证据为准。
